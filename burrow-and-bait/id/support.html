Pertanyaan yang sering diajukan

1. Saya menginstal ulang game / punya ponsel baru. Bagaimana cara mengembalikan pembelian saya?
Pembelian terikat pada akun App Store atau Google Play Anda. Masuk dengan akun toko yang sama, hubungkan ke internet, lalu ketuk Pulihkan Pembelian di Toko atau di Pengaturan → Paket Anda. Pembelian tidak dapat dipindahkan antara perangkat Apple dan Google.

2. Bagaimana cara memindahkan suaka saya ke ponsel lain?
Tidak ada akun atau sinkronisasi cloud, jadi kemajuan Anda hanya ada di perangkat Anda. Di ponsel lama, buka Pengaturan → Data → Ekspor dan simpan atau kirim file cadangan ke tempat yang bisa Anda akses (misalnya File, Google Drive, atau email ke diri sendiri). Di ponsel baru, instal game, buka Pengaturan → Data → Impor, pilih file, dan konfirmasi. Lalu pulihkan pembelian (pertanyaan 1). Cadangan iCloud / Android bawaan perangkat Anda mungkin juga membawa game Anda, tetapi kami tidak dapat menjaminnya — mengekspor adalah cara yang aman.

3. Bagaimana cara menghapus semua data saya?
Pengaturan → Data → Hapus semua data, lalu konfirmasi. Ini menghapus kemajuan game, pengaturan, dan notifikasi terjadwal di perangkat ini dan tidak dapat dibatalkan — ekspor cadangan terlebih dahulu jika Anda mungkin membutuhkannya nanti. Pembelian Anda tidak hilang; Anda dapat memulihkannya kapan saja.

4. Saya tidak menerima notifikasi.
Periksa bahwa notifikasi untuk Burrow & Bait diizinkan di pengaturan perangkat dan diaktifkan di Pengaturan → Notifikasi. Secara desain, game tetap tenang antara pukul 22:00 dan 08:00 (peringatan dipindahkan ke pagi hari), mengirim paling banyak 3 kelompok peringatan per hari, dan tidak menampilkan peringatan saat Anda bermain. Notifikasi bisa tiba terlambat beberapa menit, terutama dengan penghemat baterai, Fokus/Jangan Ganggu, atau optimasi baterai agresif di beberapa ponsel Android. Hasil hewan-hewan kecil Anda selalu benar saat Anda membuka game, meskipun peringatan tidak muncul.

5. Bagaimana cara mengganti bahasa?
Pengaturan → Bahasa. Game tersedia dalam 15 bahasa: English, Tiếng Việt, 简体中文, 繁體中文, 日本語, 한국어, Español, Português (Brasil), Français, Deutsch, Italiano, Русский, العربية, हिन्दी, dan Bahasa Indonesia. Secara default mengikuti bahasa ponsel Anda.

6. Bisakah saya mendapatkan pengembalian dana?
Pembayaran ditangani oleh Apple atau Google, jadi pengembalian dana diminta dari mereka:

  • App Store: https://support.apple.com/en-us/118223 (reportaproblem.apple.com)
  • Google Play: https://support.google.com/googleplay/answer/2479637?hl=id

Jika pembelian dikembalikan dananya, kontennya dikunci kembali tetapi kemajuan Anda tetap tersimpan. Semua paket adalah pembelian satu kali — tidak ada langganan yang perlu dibatalkan.

7. Apakah game mengirim data saya ke suatu tempat?
Game Anda tetap di perangkat Anda. Tidak ada iklan, akun, atau pelacakan. Game hanya menghubungi RevenueCat (untuk mengonfirmasi pembelian) dan Expo (untuk mengunduh pembaruan aplikasi), dengan data teknis terbatas — tidak ada layanan analitik atau pelaporan crash. Lihat Kebijakan Privasi kami untuk detailnya: https://lt24appmaker.github.io/burrow-and-bait/id/privacy.html

8. Apakah saya harus online untuk bermain?
Tidak. Semuanya berfungsi offline. Perangkap dan sarang Anda tetap "berjalan" saat game ditutup dan hasilnya dihitung saat Anda kembali. Anda hanya memerlukan internet untuk membeli, memulihkan pembelian, dan menerima pembaruan.

9. Ada yang salah / saya menemukan bug. Bagaimana menghubungi Anda?
Gunakan Pengaturan → Kirim masukan, atau kirim email ke lt24appmaker@gmail.com dengan deskripsi singkat dan, jika memungkinkan, tangkapan layar. Jika game menampilkan layar kesalahan saat dimulai, mohon jangan hapus aplikasi sebelum menghubungi kami — data simpanan Anda mungkin masih dapat dipulihkan di perangkat.
